用途说明 · Purpose Statement

MoldTrend Research
DIY 硅胶模具趋势研究工具

一个用于内部市场研究的数据分析工具：研究美国市场 DIY 硅胶模具 / 树脂模具的 设计元素（造型母题）与 产品形态（蜡烛、托盘、吊坠、收纳盒等） 正在发生的趋势变化。

这个工具做什么

  • 把「公开的市场关注度信号」（例如关键词搜索热度，只代表关注度， 不代表销量）与「通过平台官方 API 授权获取的公开商品元数据」放在一起分析。
  • 建立一套可追溯的标签体系：把商品拆解为元素（如海龟、蝴蝶结、蘑菇）与形态 （如带盖收纳盒、吊坠、托盘），再观察哪些组合在持续出现。
  • 对每条结论标注来源等级与证据强度；证据不足时明确写 「暂无可靠数据」，而不是给出一个看起来精确的数字。
  • 输出面向研究者阅读的趋势报告与证据页面，用于内部判断设计方向。

这个工具不做什么

  • 不销售、不代购、不铺货，不做任何交易行为；
  • 不展示或转售平台商品内容，也不镜像平台界面；
  • 不收集、不存储买家或卖家的个人信息；
  • 不抓取需要登录才能访问的内容；
  • 不绕过验证码、访问限制或频率限制，不做反爬对抗；
  • 不使用非公开接口，不冒充官方客户端；
  • 不接入 Amazon 公开页面数据；
  • 不对外提供数据下载、数据接口或数据转售。

数据与合规原则

  • 来源必须可标注：每条数据都带来源等级（平台官方 API / 公开信号 / 派生指标 / 示例数据），非官方来源永远不会被标成官方数据。
  • 口径不越界：搜索热度是相对关注度、排名是排名、公开计数不是销量； 不做任何换算或臆测。
  • 存储最小化：遵守平台条款的保留要求。就 Etsy 而言，商品内容 （标题、图片、价格等）最长保留 24 小时、对外展示新鲜度不超过 6 小时； 仅长期保留我们自行计算的派生标签与聚合统计。
  • 不用示例数据填补真实缺口：数据不足就如实写不足。

English summary

MoldTrend Research is an internal market-research tool that studies which design elements and product forms are trending for DIY silicone and resin molds in the US market. It combines publicly available interest signals (search interest — an interest metric, not sales) with public listing metadata obtained through official platform APIs.

Every data point carries a source level and an evidence strength; when evidence is insufficient the tool reports “no reliable data” rather than an invented number. It does not sell products, does not resell or mirror platform content, does not collect personal data, does not access login-gated content, and does not bypass captchas, access controls or rate limits. It does not use Amazon public-page data.

This page is a purpose statement only. It contains no source code, no database, no collected data and no credentials, and loads no third-party resources.
