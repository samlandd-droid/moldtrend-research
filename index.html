MoldTrend Research
Trend research for DIY silicone molds

An internal, read-only market-research tool that studies which design elements (motifs such as sea turtle, bow, mushroom) and product forms (candle, tray, pendant, trinket box, and so on) are trending for DIY silicone and resin molds in the US market.

What this tool does

  • Combines publicly available market-interest signals (for example keyword search interest — an interest metric that is not a sales figure) with public listing metadata obtained through official platform APIs.
  • Organizes findings into consistent, traceable categories so that recurring combinations of design element and product form can be observed over time.
  • Labels every conclusion with a source level and an evidence strength. When the evidence is insufficient, it reports “no reliable data” instead of an invented number.
  • Produces trend summaries and evidence pages intended for internal reading.

What this tool does not do

  • Does not sell, buy, dropship or automate any seller-side action; it performs no transactions.
  • Does not display, resell or mirror platform listings or platform interfaces.
  • Does not collect or store buyer or seller personal data.
  • Does not access member-only, private or login-gated content.
  • Does not bypass captchas, access controls or rate limits, and does not attempt to evade anti-bot measures.
  • Does not use private or undocumented endpoints, and does not impersonate official clients.
  • Does not scrape marketplace public web pages; access is limited to official APIs and public signals.
  • Does not offer data downloads, data feeds or data resale to anyone.

Data and compliance principles

  • Source labelling. Every data point carries a source level (official platform API / public signal / derived metric / sample data). A non-official source is never labelled official.
  • No overreach in meaning. Search interest is relative interest, a rank is a rank, and a public counter is not a sale. No conversions and no guesses.
  • Data minimisation. Retention is kept to the minimum that each platform's terms require; only our own derived, aggregated statistics are kept long term.
  • Link-back. Where the tool retains a reference to a product, it keeps a direct link back to the original listing on the platform.
  • No sample data as a stand-in. If real data is missing, the tool says so.

Scope and about this site

  • The tool is internal and read-only: it provides no service and is not open to the public.
  • This site states the project's purpose only: it contains no source code, no database, no collected data and no credentials.
  • This site is static: no JavaScript, no cookies, no third-party resources, no analytics.
