# moldtrend-research

Public **purpose statement** page (GitHub Pages). It publishes the project's intended use only — **no source code, no database, no credentials and no collected data**.

- Page: `index.html` — static: **no JavaScript, no cookies, no third-party resources, no analytics**
- Content: what the tool does / does not do, data and compliance principles, scope, and the **Etsy trademark disclaimer**

## This repository does not contain

- any source code (the application is not published here)
- any database contents or database files
- any API keys, tokens or credentials
- any internal documents, logs or operational data
- any platform listing content, or buyer/seller personal data

## Deployment

GitHub Pages serves this repository from the root of the `main` branch.
To update the statement, edit `index.html`, commit and push.
