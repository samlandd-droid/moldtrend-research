# moldtrend-research

Public **purpose statement** site for MoldTrend Research (GitHub Pages). It publishes the project's intended use only — **no source code, no database, no credentials and no collected data**.

- `index.html` — purpose statement, the Etsy notice required by Etsy, and contact details
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service

All pages are static: **no JavaScript, no cookies, no third-party resources, no analytics**.
